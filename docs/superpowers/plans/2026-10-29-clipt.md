# Clipt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Clipt, a fast, Liquid Glass, Spotlight-style clipboard history app for macOS: ⌘⇧C, ↓↓, ↩, pasted.

**Architecture:** A Swift package in the shape of Glint. `CliptCore` holds everything testable without UI: pasteboard snapshot filtering and classification, the SQLite/FTS5 store with blobs on disk, retention, the panel's list and selection model, placement and paste decisions, and update checks. `Clipt` is the AppKit/SwiftUI app: the clipboard monitor, a pre-built non-activating glass `NSPanel`, the paster, the menu bar, Settings, onboarding and the updater. `CliptTests` is a plain executable test runner, like `GlintTests`.

**Tech Stack:** Swift 6, SwiftUI inside AppKit, the system `libsqlite3` (FTS5), ImageIO, Vision, Carbon `RegisterEventHotKey`, `CGEvent`, `SMAppService`. No third-party dependencies.

**Spec:** `docs/superpowers/specs/2026-10-29-clipt-design.md`, with mockup `docs/superpowers/specs/mockups/panel.html`. Read both before any task.

## Global Constraints

- macOS 26 or later (`LSMinimumSystemVersion` 26.0, `.macOS(.v26)`). Develop and test on macOS 27.
- Swift 6 language mode. No third-party packages.
- Bundle id `com.brentc22.Clipt`. App name `Clipt`. `LSUIElement` true (menu bar app, no Dock icon).
- All UI text is in English.
- Default global hotkey is ⌘⇧C. The user can remap it.
- The default history limit is 1,000 unpinned items. Options are 200, 1,000, 5,000 or unlimited. Age limit options are 1 day, 7 days, 30 days or forever, default forever. Pins never expire and don't count.
- Per-item storage cap is 20,000,000 bytes. Above that, keep only the types Clipt understands.
- Ignored pasteboard types: `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, `org.nspasteboard.AutoGeneratedType`, `com.agilebits.onepassword`, `de.petermaurer.TransientPasteboardType`. Clipt checks these before reading any content.
- The ignored-apps list starts with: `com.apple.Passwords`, `com.apple.keychainaccess`, `com.1password.1password`, `com.bitwarden.desktop`.
- Data lives in `~/Library/Application Support/Clipt/`. The only network traffic is the update check.
- Performance targets: the panel is visible within 16 ms of the hotkey on a warm start; search over 10k items takes under 50 ms; memory stays roughly flat from 100 to 10k items. The list loads in pages of 50.
- Every animation goes through `Motion`. With Reduce Motion on, animations become plain fades.
- Code signing identity is `Clipt Self-Signed`, used locally and in CI. Releases are never signed ad-hoc.
- Commits are in English and end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Huge copies**, such as a 5 MB log or a 30 MB image. Capture must not stall, the row preview must stay one short line, and search must stay fast. Tested in Task 2 (classifier cap) and Task 3 (insert and search with a 5 MB item).
2. **Empty or unreadable pasteboards**, such as file promises or an app that clears the clipboard. Clipt must ignore them silently, without storing an empty item or crashing. Tested in Task 2.
3. **Clipt's own paste coming back through the monitor.** It must not create a duplicate or change the source app; the item only moves to the top. Tested in Task 3 (`touch`) and Task 4 (`OwnWriteTracker`).
4. **No app to paste into**, for example when the panel opens over the desktop, or the previous app quit while the panel was open. Clipt must copy the item and tell the user to press ⌘V. Tested in Task 5.
5. **A corrupt or unreadable database** after a crash or disk issue. Clipt must move the file aside and start fresh, not crash on launch. Tested in Task 3.

  public struct ClipItem: Sendable, Identifiable, Equatable {
      public let id: Int64; public let kind: ClipKind; public let preview: String
      public let sourceBundleID: String?; public let sourceAppName: String?
      public let copiedAt: Date; public let isPinned: Bool; public let byteSize: Int
      public let thumbnailURL: URL?     // images only, ≤ 256 px PNG
  }
  public enum KindFilter: String, Sendable, CaseIterable { case all, text, images, links }   // chip order; .text matches .text + .color + .file
  public struct RetentionPolicy: Sendable, Equatable {
      public var maxItems: Int?          // nil = unlimited; default 1000
      public var maxAge: TimeInterval?   // nil = forever; default nil
      public static let `default`: RetentionPolicy
      public static let itemOptions: [Int?] = [200, 1000, 5000, nil]
      public static let ageOptions: [TimeInterval?] = [86_400, 604_800, 2_592_000, nil]
  }
  public final class ClipStore {        // not thread-safe: the app owns one on a serial queue
      public init(directory: URL) throws   // creates clipt.sqlite (WAL) + blobs/; a corrupt db is moved to clipt.sqlite.corrupt-<unix time> and recreated
      @discardableResult public func insert(_ c: ClipContent, sourceBundleID: String?, sourceAppName: String?, at: Date = Date()) throws -> ClipItem
                                            // same primaryHash exists → bump copiedAt (and source) instead of a new row
      public func touch(_ id: Int64, at: Date = Date()) throws          // move to top, keep source
      public func pinned(filter: KindFilter) throws -> [ClipItem]        // pin order = pinnedAt ascending
      public func recent(filter: KindFilter, limit: Int, offset: Int) throws -> [ClipItem]   // unpinned, newest first
      public func search(_ query: String, filter: KindFilter, limit: Int) throws -> (pinned: [ClipItem], recent: [ClipItem])
      public func representations(of id: Int64) throws -> [Representation]
      public func fullText(of id: Int64) throws -> String?
      public func setPinned(_ id: Int64, _ pinned: Bool) throws
      public func delete(_ id: Int64) throws                              // removes unreferenced blobs
      public func clearHistory() throws                                   // keeps pins
      public func setRecognizedText(_ text: String, for id: Int64) throws // OCR text into FTS
      public func enforce(_ policy: RetentionPolicy, now: Date = Date()) throws
      public func count() throws -> Int
  }
  public enum Thumbnailer { public static func png(from imageData: Data, maxPixel: Int = 256) -> Data? }   // ImageIO
  ```
  - **Schema** (decided): `items(id INTEGER PRIMARY KEY, hash TEXT UNIQUE, kind TEXT, preview TEXT, plain_text TEXT, source_bundle TEXT, source_name TEXT, copied_at REAL, pinned_at REAL NULL, byte_size INTEGER, thumb TEXT NULL)`, an index on `(pinned_at, copied_at DESC)`, and `reps(item_id, ord, type, blob TEXT, size)`.
  - **Search index:** `fts USING fts5(plain_text, ocr_text, content='', tokenize='unicode61 remove_diacritics 2')`, keyed by rowid = item id.
  - **Blobs:** stored as `blobs/<sha256>`. Identical data is shared.
  - **Versioning:** `PRAGMA user_version = 1`.

  // Core
  public enum CaptureState: Equatable, Sendable { case active, pausedByUser, noPasteboardAccess }
  public enum CaptureGate { public static func state(userPaused: Bool, accessAllowed: Bool) -> CaptureState }   // user pause wins
  public struct OwnWriteTracker: Sendable {
      public mutating func recordWrite(changeCount: Int, itemID: Int64)
      public mutating func claim(changeCount: Int) -> Int64?   // returns the item id once if this change was ours
  }
  // App
  @MainActor final class Prefs { static let shared: Prefs   // UserDefaults-backed
      var hotKey: HotKeys.Combo; var retention: RetentionPolicy; var ignoredApps: [String]; var capturePaused: Bool
      var showMenuBarIcon: Bool; var motionEnabled: Bool; var onboardingDone: Bool }
  @MainActor final class History: ObservableObject {   // the one owner of ClipStore; store work runs on a private serial queue
      static let shared: History
      @Published private(set) var captureState: CaptureState
      @Published private(set) var revision: Int          // bumps after every change; the panel reloads on it
      func recent(filter: KindFilter, limit: Int, offset: Int) async -> [ClipItem]
      func search(_ q: String, filter: KindFilter) async -> (pinned: [ClipItem], recent: [ClipItem])
      func pinned(filter: KindFilter) async -> [ClipItem]
      func representations(of id: Int64) async -> [Representation]
      func fullText(of id: Int64) async -> String?
      func setPinned(_ id: Int64, _ on: Bool); func delete(_ id: Int64); func clearHistory()
      func didWriteOwn(changeCount: Int, itemID: Int64)  // called by the paster
  }
  final class PasteboardMonitor   // owned by History
  ```
